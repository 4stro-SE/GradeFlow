"# Academic Grade Average & Prediction Calculator"

"## Project Overview"
"This lightweight desktop application, developed in Python, is designed to simplify and optimize academic performance tracking for students. Unlike basic calculators, this tool integrates an automatic weighting algorithm capable of handling complex coefficient structures (such as those used in French and international school systems) alongside a predictive grade simulation module."

"This project is a core component of my software development portfolio, showcasing my skills in algorithmic logic, clean code architecture, and functional user interface design."

"---"

"## Detailed Core Features"

"1. Real-Time Weighted Calculation"
"Dynamic entry for academic grades based on a standard 0-to-20 scale or custom grading metrics. The application instantly recalculates the overall grade average as soon as a coefficient or score is modified, with no need to manually refresh or restart the interface."

"2. Custom Weighting and Course Management"
"Allows users to structure academic data by school subjects (Mathematics, Sciences, Languages, etc.) and assign specific weights or coefficients to individual tasks, exams, or entire course categories."

"3. Predictive Simulation Module (Target Grade Objective)"
"Users can set a target final average they want to achieve by the end of the school term. The built-in algorithm automatically computes the exact minimum score required on the upcoming exam or assignment to successfully reach that academic goal."

"4. Local Data Persistence"
"Features a lightweight local storage structure to save user data automatically, ensuring students do not have to re-enter their courses and grades every time the software is opened."
